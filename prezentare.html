Ce poate fiecare utilizator

Patru tipuri de cont. Două axe separate: senioritate și permisiuni.

Scriptica Super Admin
Administrează platforma.
  • Creează conturi businessStandard
  • Configurează pachete / tier-uriTier
  • Pauză / anulare contracteStandard
  • Denumire instanță ↔ clientStandard
  • Bootstrap anexe / tipuri pentru clienți noiStandard
Business Admin (admin local)
Constructorul principal de fluxuri.
  • Utilizatori interni / externiStandard
  • Funcție + nivel de senioritateStandard
  • Construiește anexeTier
  • Tipuri de fluxuri (contabil / audit)Tier
  • Setează permisiuniStandard
  • Backup localTier
Angajat
Execută munca.
  • Lucrează situații / misiuniStandard
  • Time trackingStandard
  • ChatStandard
  • Documente cu sortare AITier
  • Echipă pe misiuni de auditStandard
Customer
Parte externă.
  • Încarcă / vede documentele propriiStandard
  • Vede stadiul situației / misiuniiStandard
  • ChatStandard
  • La audit = entitate auditatăStandard
Autoritate Decidentă rol extern de aprobare · NU senioritate
Conducătorul entității auditate avizează raportul — axă separată de echipă.
  • Vede misiunile read-onlyStandard
  • Coadă „Spre Aprobare"Standard
  • Aprobă / Cere modificări / RespingeStandard
Senioritate = experiență (etichetă). Permisiune = ce ai voie (separat). Gating comercial = Super Admin alege ce primește fiecare client.
